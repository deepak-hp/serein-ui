# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/deepak-hp/serein-ui/security/advisories/new). Do not post suspected vulnerabilities in a public issue.

Private vulnerability reporting was enabled and verified for this repository on 13 October 2026. Reports are shared privately with repository maintainers. No response-time guarantee is offered during beta.

Reports should include the affected version or commit, a minimal reproduction, impact, and any mitigation already known. Do not include credentials or personal data. See [GitHub's configuration guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
