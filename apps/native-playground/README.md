# Serein native playground

An Expo (SDK 58) app showing `@serein-ui/native` in light and dark side by side. The page itself can follow the system or be forced to either theme.

```bash
pnpm build                                        # once, from the repository root: builds tokens, fonts and @serein-ui/native
pnpm --filter @serein-ui/native-playground start  # then press i, a or w, or scan the QR code
```

Runs in Expo Go for SDK 58 (scan the QR code), on the web (`w`) or in a simulator.
