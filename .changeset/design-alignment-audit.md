Align every web component with the Serein design language in light and dark. Type follows the Serein scale (no 14px, weights 300–600). Selection marks are ink and segmented controls are a raised key on a sunken track, so the signal stays for actions, needles and today. Loading uses the Drizzle, focus offset is 2px, and machined corners replace pills. Adds the `color.scrim` token for modal backdrops. See docs/audits/2026-10-25-design-alignment.md.
