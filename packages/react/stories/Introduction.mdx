# Serein

A precise, calm component language: fine graduations, exact readouts and one vivid vermilion signal, set in Anek Latin with Chivo Mono for measurements. Read **Foundations** for colour, type, spacing and icons.

Choose a component in the sidebar. Use **Theme** to compare light and dark, **Controls** to change props, and **Accessibility** to inspect the rendered example. The **Motion** toolbar follows your system preference unless you explicitly choose to preview animations.

Serein is an unpublished React web library. Its native mobile and desktop adapters are not implemented yet.
