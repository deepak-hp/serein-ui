# Spacing, radius and motion

Nine spacing steps on a 4px grid (the graduations use the same pitch). Radii are machined, slightly softened corners, never pills. Scales and gauges stay square.

Motion is fast and exact. Things that come to rest (the tape, the needle, the gauge) use `easing-settle`; everything else uses `easing-standard`. With reduced motion on, movement becomes a near-instant change or a fade, and every outcome is still announced.
