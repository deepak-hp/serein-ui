# Icons

Every icon is drawn for Serein on a 20px grid, with a 1.5px stroke, square caps and mitred joins, in `currentColor`. Place icons beside a word. An icon-only control needs an `aria-label`.

The set lives in `@serein-ui/icons` (SVG strings, `.svg` files and React components). It is not yet published separately.
