# @serein-ui/fonts

Self-hosted Serein typefaces, with no third-party font CDN:

- **Anek Latin** (variable weight and width) for text and readouts
- **Chivo Mono** for measurements, units and references

```css
@import '@serein-ui/fonts';
```

Your bundler copies the referenced `.woff2` files from `@serein-ui/fonts/files/`. `@serein-ui/react` bundles the same fonts as `@serein-ui/react/fonts.css`.
